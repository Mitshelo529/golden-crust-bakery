# Golden Crust Bakery Website — Part 2

## Project Information
- Module: Web Development (Introduction) — WEDE5020

- Organisation: Golden Crust Bakery
- Location: Johannesburg, South Africa
- Part: Part 2 — CSS Styling and Responsive Design

## Project Overview
This Part 2 website develops the five-page Golden Crust Bakery website from Part 1. The update focuses on external CSS styling, typography, CSS Grid and Flexbox layouts, decorative styling, interactive pseudo-classes and responsive design for desktop, tablet and mobile screens.

## Pages
- index.html — Home
- about.html — About
- products.html — Products
- enquiry.html — Enquiry
- contact.html — Contact

## Part 2 CSS Work Completed
- One external stylesheet is linked to all five HTML pages.
- Base styling was added for the body, headings, links, images and sections.
- Typography uses responsive relative units and a clear heading hierarchy.
- CSS Grid and Flexbox are used for the hero, cards, forms, navigation, split sections and footer.
- Borders, backgrounds and box shadows were added for visual structure.
- :hover, :focus and :active pseudo-classes were added to interactive elements.
- Tablet and mobile media queries were added at 900px and 600px.
- Navigation changes from a horizontal layout to a stacked mobile layout.
- Images use the picture element for responsive image handling and CSS max-width: 100%.
- Forms, cards and the map area adjust to smaller screens.

## Part 1 Review / Updates
Part 2 includes detailed development updates based on review of the Part 1 website and the Part 2 requirements. The plain Part 1 foundation was retained while improving presentation, consistency, responsive behaviour, navigation, interactive states and image handling. No lecturer feedback has been invented; where no specific written feedback was supplied, the changes are documented as Part 2 review and requirement updates.

## Testing
The website was tested at three viewport sizes:
- Desktop: 1366 × 768
- Tablet: 768 × 1024
- Mobile: 390 × 844

The checks included page layout, navigation wrapping/stacking, responsive typography, images, forms and general readability.
