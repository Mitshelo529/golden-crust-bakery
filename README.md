## Project overview

Golden Crust Bakery is a demonstration website for a bakery. It presents the bakery, its products, and ways for visitors to make an enquiry or contact the business. Part 3 builds on the earlier website by adding JavaScript functionality, form validation, search, image enlargement, and SEO files.

## Website pages

- `index.html` — home page
- `about.html` — information about the bakery
- `products.html` — bakery products and product search
- `enquiry.html` — bakery order and enquiry form
- `contact.html` — contact information and general contact form

## Part 3 functionality

- **Product search:** filters product cards as a visitor types.
- **Enquiry form:** checks required details and displays a demonstration response based on the enquiry.
- **Contact form:** validates the visitor's details and prepares an email draft addressed to `info@goldencrustbakery.co.za`. The visitor must review and send the draft; the website does not send the email automatically.
- **Image lightbox:** lets visitors enlarge supported product and gallery images, with Escape to close.
- **FAQ accordion:** retains the existing expandable FAQ content.

The forms use client-side demonstration behaviour. They do not save submissions to a server or database.
